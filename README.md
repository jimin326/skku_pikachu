# skku_pikachu

- `Lion_Eating_Bank_v1.js`, `Lion_Eating_Bank_v2.js`: tournament bots
- `bot-dev/rl/`: real-physics harness, PPO trainer, evaluator, exporter, and loss analysis

RL setup and commands are documented in [`bot-dev/rl/README.md`](bot-dev/rl/README.md).
The tournament engine is intentionally not modified or vendored here. Run
`scripts/setup_rl_engine.ps1` with an up-to-date official game checkout before
running the harness.
